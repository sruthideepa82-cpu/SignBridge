# Vocabulary reviewer worksheet (one copy per candidate class)

Use this before adding any class to `ai-engine/dataset/metadata/vocabulary.json`.
A class is marked `"verified": true` only when every box below is ticked by a named reviewer.

## Checks

- [ ] I watched the reference video or viewed the poster entry myself. I did not rely on a written summary.
- [ ] The label is an English gloss, not a copy of an ASL or BSL sign name.
- [ ] The hand count matches what the reference shows.
- [ ] The sign is static (one posture held), not a movement. Dynamic signs are out of scope for this phase.
- [ ] The reference is an official ISL source from the register, or the exception is written below with the reason.
- [ ] The meaning is specific enough that two people would label the same sign the same way.
